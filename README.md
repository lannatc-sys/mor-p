# โปรแกรมวิเคราะห์สกอร์รวม (Over/Under)

วิเคราะห์ **สกอร์รวม** ของนัดที่ยังไม่เริ่มแข่ง สำหรับ 4 ชนิดกีฬา

| กีฬา | ลีก (ชื่อย่อที่ใช้ในคำสั่ง) | โมเดลการกระจายของสกอร์ |
|---|---|---|
| บาสเกตบอล | `nba` `wnba` `ncaab` `ncaaw` `euroleague` `eurocup` | แจกแจงปกติ |
| ฟุตบอล | `epl` `laliga` `seriea` `bundesliga` `ligue1` `ucl` `uel` `nations` `thaileague` `mls` `jleague` `eredivisie` `championship` หรือ `soccer:<รหัส ESPN>` | ปัวซองต่อทีม |
| เบสบอล | `mlb` `ncaabase` | ทวินามลบต่อทีม |
| อเมริกันฟุตบอล | `nfl` `ncaaf` | แจกแจงปกติ |

ดึงข้อมูลนัดแข่ง ผลย้อนหลังของทีม และราคาสกอร์รวมของเจ้ามือ (ถ้ามี) จาก ESPN public API อัตโนมัติ
ยกเว้นยูโรลีก/ยูโรคัพ ที่ดึงจาก API ทางการ `api-live.euroleague.net` (ไม่มีราคาเจ้ามือ ต้องกรอกไลน์เอง)
ไม่ต้องสมัครหรือใช้ API key และไม่ต้องติดตั้งไลบรารีเพิ่ม (ใช้ Python 3.9 ขึ้นไป)

## ใช้บนมือถือ (iPhone)

เปิดหน้าเว็บ **ป้ายสกอร์รวม** ในแอป Claude: https://claude.ai/artifact/CaNq5YNoTF9QCZRRgTYHnx

- แท็บ "นัดก่อนเริ่มเกม" แสดงนัดที่ยังไม่เริ่มพร้อมผลวิเคราะห์ แตะนัดเพื่อดูรายละเอียดและปรับไลน์/ราคาเอง
- แท็บ "คำนวณเอง" กรอกค่าเฉลี่ยของสองทีมแล้วคำนวณได้ทันที (ไม่ต้องรอข้อมูล)
- ข้อมูลนัดอัปเดตเมื่อสั่ง Claude ว่า "อัปเดตป้ายสกอร์รวม" (ขั้นตอนอยู่ใน `CLAUDE.md`)
- ซอร์สของหน้าเว็บ: `web/index.html` ข้อมูลสร้างด้วย `python -m sports_total export`

## เริ่มใช้งาน

```bash
python -m sports_total leagues                         # ดูลีกที่รองรับ
python -m sports_total games nba --date tomorrow       # ดูรายการนัด + ไลน์สกอร์รวม
python -m sports_total analyze nba --date tomorrow     # วิเคราะห์ทุกนัดที่ยังไม่เริ่ม
python -m sports_total analyze epl --date 2026-11-21 --days 3          # ฟุตบอลทั้งสุดสัปดาห์
python -m sports_total analyze nfl --team chiefs                       # เฉพาะทีม
python -m sports_total analyze mlb --event 401XXXXXX --line 8.5 --over-odds -105 --under-odds -115
python -m sports_total analyze nba --json > nba.json                   # ส่งออก JSON
```

ติดตั้งเป็นคำสั่ง `sports-total` ได้ด้วย `pip install .`

### ใช้งานแบบไม่ต่ออินเทอร์เน็ต

```bash
python -m sports_total demo nba      # ข้อมูลจำลอง (nba / epl / mlb / nfl)
python -m sports_total manual epl --home Arsenal --away Chelsea \
    --home-for 2.1 --home-against 0.9 --away-for 1.6 --away-against 1.1 --line 2.5
```

## ตัวเลือกที่สำคัญ

| ตัวเลือก | ความหมาย |
|---|---|
| `--date` | วันที่ตามปฏิทินสหรัฐฯ (ESPN ใช้เวลา US Eastern) รับ `YYYY-MM-DD`, `today`, `tomorrow` — เกม NBA/NFL ตอนเช้าเวลาไทย มักเป็นวันก่อนหน้าในปฏิทินสหรัฐฯ |
| `--days N` | ดึงนัดต่อเนื่อง N วัน |
| `--line` `--over-odds` `--under-odds` | กำหนดไลน์/ราคาเอง (ราคาแบบอเมริกัน, ค่าเริ่มต้น -110) |
| `--last N` | ใช้ผลการแข่งขันล่าสุด N นัด (ค่าเริ่มต้น 10) |
| `--half-life H` | น้ำหนักเกมลดลงครึ่งหนึ่งทุก H นัด (ค่าน้อย = เน้นฟอร์มล่าสุด) |
| `--league-avg` | คะแนนเฉลี่ยต่อทีมของลีก ใช้แทนค่าตั้งต้นใน `sports_total/leagues.py` |
| `--include-started` | รวมนัดที่เริ่มแล้ว/จบแล้ว (ใช้ย้อนดูผลเทียบกับการคาดการณ์) |
| `--no-cache` | ไม่ใช้แคช (ปกติแคช scoreboard 5 นาที, ผลย้อนหลัง 1 ชม. ที่ `~/.cache/sports_total`) |

## หลักการคำนวณ

1. ดึงผลแข่งที่จบแล้วของทั้งสองทีม **เฉพาะก่อนเวลาเริ่มนัดนั้น** (ถ้าฤดูกาลนี้มีไม่ถึง N นัด จะเติมจากฤดูกาลก่อน)
2. ค่าเฉลี่ยคะแนนได้/เสียแบบถ่วงน้ำหนัก ให้เกมล่าสุดมีน้ำหนักมากกว่า
3. หดค่าเข้าหาค่าเฉลี่ยลีกเมื่อข้อมูลน้อย ป้องกันการตีความเกินจริงจากไม่กี่นัด
4. คะแนนคาดการณ์ของแต่ละทีม = ค่าเฉลี่ยลีก × (พลังบุกทีมเรา) × (พลังรับคู่แข่ง) ± ความได้เปรียบเจ้าบ้าน
5. ถ้ามีไลน์เจ้ามือ (หรือกรอกไลน์เองในนัดที่ไม่มีราคาเจ้ามือ): หาสกอร์รวมที่ไลน์+ราคาบอกไว้
   แล้วผสม โมเดล 40% / ตลาด 60% (`--model-weight`, ใส่ 1 เพื่อใช้โมเดลล้วน)
   เพราะโมเดลที่ใช้แค่ผลย้อนหลังมักต่างจากตลาดมากเกินจริง
6. แปลงเป็นความน่าจะเป็นสูง/ต่ำ/เสมอไลน์ ตามการกระจายที่เหมาะกับกีฬานั้น
7. เทียบกับราคา: `edge` = โอกาสตามโมเดล − โอกาสที่ราคาบอกไว้ (breakeven)
   - edge ≥ 6% → **แนะนำ**, 3–6% → **เอนเอียง**, น้อยกว่านั้น → **ผ่าน**
   - ลดระดับเป็น "เอนเอียง" อัตโนมัติ เมื่อข้อมูลน้อย หรือโมเดลต่างจากไลน์ตลาดมากผิดปกติ

ฟุตบอลแสดงเพิ่ม: โอกาสชนะ/เสมอ/แพ้, ยิงได้ทั้งสองทีม (BTTS), สกอร์ที่น่าจะเป็น, การกระจายจำนวนประตู
เบสบอลแสดงเพิ่ม: โอกาสชนะ, สกอร์ที่น่าจะเป็น

## ข้อจำกัด

- ใช้เพียงผลงานย้อนหลัง ยังไม่รวมผู้เล่นบาดเจ็บ/ตัวจริง ผู้ขว้างตัวจริง (เบสบอล) สภาพอากาศ หรือตารางแข่งถี่
  ถ้าโมเดลต่างจากไลน์มาก โปรแกรมจะเตือน — ตลาดมักรู้ข้อมูลเหล่านี้
- ESPN API ไม่ใช่ API ทางการที่มีเอกสารรับรอง โครงสร้างอาจเปลี่ยน และบางลีก/บางนัดอาจไม่มีราคาเจ้ามือ
- ค่าตั้งต้นของแต่ละลีก (`team_avg`, `total_sd`, `home_adv`) เป็นค่าประมาณ ควรปรับตามฤดูกาลจริงใน `sports_total/leagues.py`
- ผลวิเคราะห์เป็นการประมาณทางสถิติ ไม่รับประกันผล
